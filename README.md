# Интеграция с Unisender

Целью данного проекта является создание интеграции для синхронизации контактов с аккаунта в систему Unisender. Проект включает в себя разработку серверной части с использованием языка Go, а также взаимодействие с базой данных MySQL, очередями сообщений Beanstalk и системой WebHook для обработки изменений данных.
Этапы разработки:

1. ### Первая неделя:

   Знакомство с операционной системой Ubuntu, Docker и языком программирования Go.
   Настройка и изучение среды разработки.

2. ### Вторая неделя:

   Разработка основного каркаса приложения.
   Написание HTTP-сервера для обработки запросов.
   Изучение принципов чистой архитектуры.
   Построение модели предметной области и составление её схемы.

3. ### Третья неделя:

   Разработка технического задания (ТЗ) для проекта.
   Построение диаграммы последовательности действий для синхронизации контактов.
   Сборка и запуск Docker-контейнера с MySQL, а также подключение административной панели.
   Подключение к серверу и добавление виджета для получения API-ключа из Unisender.

4. ### Четвертая неделя:

   Разработка gRPC-сервера для удаления аккаунта из базы данных.
   Настройка и подключение системы очередей сообщений Beanstalk.
   Реализация WebHook для отслеживания событий с контактами (создание, изменение, удаление).
   Разработка продюсеров и системных работников для обработки сообщений.
   Создание CLI-интерфейса для взаимодействия с работниками через библиотеку urfave.

## Технологии:

    Go (Golang) — основной язык программирования.
    Docker — для контейнеризации приложения.
    MySQL — для хранения данных.
    Beanstalk — очередь сообщений для обработки задач.
    gRPC — для реализации сервисов удаления аккаунта.
    Unisender API — для интеграции с платформой Unisender.

## Структура проекта:

Проект использует чистую архитектуру, разделяя логику на несколько слоев:

    Handlers — обработка HTTP-запросов.
    Usecases — бизнес-логика.
    Repositories — взаимодействие с базой данных и внешними сервисами.
    Entities — описание основных сущностей
